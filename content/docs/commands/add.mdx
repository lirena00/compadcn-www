---
title: add
description: Install selected components from your configured registries.
---

```npm
npx shadcn-plus@latest add
```

Type to search, use **↑ / ↓** to move, **Tab** to select, and **Enter** to review. Selections survive filtering. **Esc** cancels before installation.

## Name components directly

```npm
npx shadcn-plus@latest add button @company/user-menu
```

Bare names use your app's `@shadcn` source. Qualified names use the matching configured registry.

| Option | Purpose |
| --- | --- |
| `--cwd ./apps/web` | Install into one application package. |
| `--registry @company` | Filter the picker by namespace. |
| `--type block` / `--query dialog` | Narrow picker choices. |
| `--overwrite` | Allow replacement of existing files. |
| `--yes` | Accept an explicit selection without a prompt. |

Complete local file sets are skipped by default. Noninteractive use requires addresses **and** `--yes`:

```npm
npx shadcn-plus@latest add button --yes --json
```

<Callout type="warn" title="Installation can change your project">
The upstream shadcn installer can modify dependencies and shared configuration. Add verifies selected destination files exist; it does not provide rollback. Back up local changes first.
</Callout>
