---
title: collection create
description: Save a new, shareable list of component addresses.
---

```npm
npx shadcn-plus@latest collection create collections/dashboard.json button @blobz/avatar-profile --name "Dashboard"
```

Bare names become `@shadcn/name`. Creation does not scan a project or contact registries. It writes the named new file and missing parent directories, without overwriting existing files.

```json title="collections/dashboard.json"
{
  "collectionVersion": 1,
  "name": "Dashboard",
  "items": ["@shadcn/button", "@blobz/avatar-profile"]
}
```

Use `--description <text>` for intent. Repeated `--from <collection.json>` copies and deduplicates addresses from other collections; it does not create live inheritance.

Commit the JSON file to share it. Next: [show](/documentation/commands/collection/show) or [install](/documentation/commands/collection/install) the collection.
