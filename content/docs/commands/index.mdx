## Common flags

`--json` returns one structured response. `--plain` returns readable text. `--no-interactive` disables prompts. `--progress` sends stages to stderr; `--no-progress` hides them.

Use `--cwd <app>` where supported to target a workspace package. Append `--help` to a command for its complete option list. Put output flags before `--help` or `--version`.

Coming from v1? See [remove](/documentation/commands/remove), [preset](/documentation/commands/preset), and [migration](/documentation/migration).
