---
title: preset list
description: List built-in and custom legacy presets.
---

```npm
npx shadcn-plus@latest preset list
```

Use `--builtin` for built-in presets or `--custom` for custom presets. This command works without prompts but does not support JSON or plain output flags.

Next: [inspect a preset](/documentation/commands/preset/show). Use [collection list](/documentation/commands/collection/list) for v2 collection files.
