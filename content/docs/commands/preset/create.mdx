---
title: preset create
description: Create a custom preset in legacy storage.
---

```npm
npx shadcn-plus@latest preset create my-preset button card
```

Use `--description <text>` for intent or `--base <names>` for comma-separated base presets. This requires an interactive terminal; JSON and plain output flags are unsupported.

For new work, use [collection create](/documentation/commands/collection/create) to save a portable file with qualified registry addresses.
