---
title: preset install
description: Install a preset through the retained legacy workflow.
---

```npm
npx shadcn-plus@latest preset install my-preset
```

This requires an interactive terminal and uses the old installer path. JSON and plain output flags are unsupported.

Prefer [collection migrate](/documentation/commands/collection/migrate), then [collection install](/documentation/commands/collection/install), for the current configured-registry workflow.
