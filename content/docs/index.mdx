**shadcn-plus** is a CLI for managing components from shadcn registries. Search and install components, trace what your app uses, and review exact file changes before removing anything.

Official, custom, and private registries use the same workflow.

<Callout title="New name, same project">
shadcn-plus is the v2 name of compadcn. V2 is in development. Package-runner examples work after publication; use the source build for now. [Get started](/documentation/quick-start).
</Callout>

## The usual workflow

```npm title="In your application"
npx shadcn-plus@latest doctor
npx shadcn-plus@latest add
npx shadcn-plus@latest audit
npx shadcn-plus@latest why button
```

`doctor` checks configuration. `add` opens the component picker. `audit` reports usage without changing project files. `why` explains one result.

An unused finding is a candidate for review. Removing files takes a separate [plan and apply](/documentation/commands/plan) workflow.
